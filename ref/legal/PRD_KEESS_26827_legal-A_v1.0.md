## 1. 배경

### 요청
- HRD사업팀(유현경)이 KEESS에 법정필수교육 전용 노출 영역과 문의 접수를 요청 (2026-09-28)
- 자료: 페이지 구성안 PPTX(메모 5건), 2026 법정필수교육 소개자료 PDF, 카드뉴스 7장, 미리보기 링크 7개

### 현재 한계
1. 법정교육이 /content 6개 축 중 하나(#ax5)로만 존재 → 인지되기 어려움
2. 과정별 썸네일·미리보기·소개서·전용 문의가 없음 → 검증과 전환 단계 부재
3. 문의 폼에서 희망 과정을 받지 못해 영업이 재확인해야 함
4. 기존 #ax5 연도별 시리즈 설명에 외부 방송·영화 작품명이 노출되어 권리 리스크 존재

### 이번 산출물의 역할
- 요청자가 노출 A안(GNB 칩 + 별도 페이지)과 노출 B안(홈 캠페인 카드 + /content 섹션)을 **실제 화면으로 비교**하기 위한 첫 번째 시안
- 법정 콘텐츠를 모듈로 만들어 노출 B안에서 재조립

> "법정교육을 한 곳에서 보고, 확인하고, 바로 문의하는 페이지. PC·태블릿·모바일 어디서나 같은 품질로."

## 2. 요구사항 분석

### [R1] GNB 진입점
- 표면 요청: GNB에 '2026 법정필수교육' 표시
- 진짜 의도: 모든 페이지 상단에서 법정교육 존재를 알림
- 해결 문제: 법정교육 인지 부족
- 성공한 모습: 어떤 페이지, 어떤 기기에서든 한 번의 탭으로 /legal 진입, GNB 레이아웃 깨짐 없음

### [R2] 소개 영역 (구성안 섹션 1)
- 표면 요청: 배지, 헤드라인, 강점 3줄, 썸네일 그리드, 해시태그
- 진짜 의도: '여기서 법정교육을 한 번에 해결할 수 있다'는 첫인상
- 해결 문제: 방문자가 과정 구성을 즉시 파악하지 못함
- 성공한 모습: 첫 화면에서 과정 7종과 핵심 가치가 보이고, 문의·소개서 행동이 바로 가능

### [R3] 자료 영역 (구성안 섹션 2, 메모 ①③④)
- 표면 요청: 카드뉴스 7장 재생, 소개자료 다운로드, 대표과정 미리보기 7개
- 진짜 의도: 구매 전 콘텐츠 품질 검증
- 해결 문제: 품질 확인 수단 부재로 문의 전 이탈
- 성공한 모습: 과정마다 미리보기로 바로 연결, 소개서는 정보 입력 후 즉시 다운로드, 카드뉴스는 기기별 자연스러운 조작

### [R4] 문의 영역 (구성안 섹션 3, 메모 ⑤)
- 표면 요청: 희망과정 체크박스 + 기타 텍스트, 예상 교육인원
- 진짜 의도: 영업이 재확인 없이 제안에 착수할 수 있는 리드 데이터
- 해결 문제: 일반 문의와 섞인 법정 리드, 희망 과정 불명확
- 성공한 모습: 접수 데이터에 관심 영역 '법정 필수', 희망과정 목록, 인원이 함께 기록

### [R5] 반응형 (내부 필수 조건)
- 표면 요청: PC·모바일·태블릿 모두 자연스럽게
- 진짜 의도: 원 소스 유지로 운영 부담 없이 전 기기 품질 확보
- 해결 문제: 기기별 깨짐, 별도 모바일 구현에 따른 불일치
- 성공한 모습: 기준 9폭 전부에서 가로 스크롤·겹침·잘림 0, 터치 44px 이상

### 요구사항 매핑

|---|---|---|

## 3. 사용자와 여정

### 페르소나
- **HR 교육 담당자 (핵심):** 연 1회 의무교육 이행 책임. 누락·증빙 부담. 과정 구성과 콘텐츠 품질, 운영 편의가 판단 기준
- **경영지원 겸직 담당자 (중소기업):** 법정교육 종류 자체를 정확히 모름. 한 곳에서 해결하길 원함
- 주요 접속 기기: 업무 중 PC, 이동 중 모바일, 회의실 태블릿

### 여정

| 단계 | 사용자 질문 | 화면 | 기능 |
|---|---|---|---|
| 진입 | 법정교육도 하나? | GNB 칩 | LF1 |
| 인지 | 어떤 과정이 있지? | 히어로, 라인업 | LF3, LF4 |
| 검증 | 콘텐츠 괜찮나? | 미리보기, 카드뉴스 | LF4, LF5 |
| 근거 | 왜 여기서? 무슨 법이지? | 법정 기준, 차별점 | LF7 |
| 보류 | 내부 보고용 자료 | 소개서 다운로드 | LF6 |
| 전환 | 우리 회사에 맞게 | 법정 문의 | LF8 |

### LF1 GNB 법정 칩 (Must)
- 기존 인재키움 칩과 같은 구조의 이벤트 칩 추가, 링크 /legal
- 정식 메뉴(NAV_ITEMS) 추가 금지 규칙 유지
- 색: `--p4` 파생 (인재키움 칩과 구분)
- 라벨: 전체 '2026 법정필수교육' / 축약 '법정필수'
- 폭별 규칙

| 폭 | 처리 |
|---|---|
| 1041px 이상 | 칩 2개 전체 라벨 |
| 941~1040px | 칩 2개 축약 라벨 |
| 940px 이하 | 드로어에 전체 라벨로 세로 배치 |

- /legal에서 법정 칩은 현재 위치 표시 (`aria-current="page"`)
- Done when: 9폭 모두에서 GNB 한 줄 유지, 겹침 0, 드로어에서 두 칩 모두 44px 이상 탭 영역

### LF2 /legal 라우트 (Must)
- 페이지 wrapper `.tint-p4`, 공통 Nav·Footer·ToTop
- 메타: title '2026 법정필수교육 | KEESS', description 1문장
- SubNav 항목: 과정 라인업 / 자료 / 법정 기준 / 도입 문의
- Done when: 직접 URL 진입, GNB 칩, /content 링크 3경로 모두 정상 진입

### LF3 히어로 (Must)
- 좌: 배지 '2026 법정필수교육', H1, 리드, 강점 3줄, CTA
- 우: 과정 썸네일 모자이크 (7개 + 권장교육 안내 타일 1개 = 2×4)
- 카피 (확정)
  - H1: `법정필수교육,` / `KG에듀원에서 한 번에`
  - 리드: `연 1회 이상 받아야 하는 재직자 필수 교육을 최신 콘텐츠로 준비했습니다. 과정 확인부터 운영까지 한 곳에서 관리하세요.`
  - 강점 3줄
    - `연 1회 이상 의무 이수 대상 과정`
    - `매년 자체 제작하는 2026년 최신 콘텐츠`
    - `권장교육까지 기업 맞춤 구성`
  - 권장교육 타일: `권장교육 과정도 함께` / `전체 과정 리스트 보기` → /content#download
- CTA: 1차 '도입 문의하기' (#legal-inquiry), 2차 '과정소개서 받기' (LF6 모달)
- Done when: 390px 첫 화면에서 H1과 1차 CTA가 스크롤 없이 보임

### LF5 카드뉴스 슬라이더 (Must, 자리 표시)
- 4:5 비율, 7장
- 재제작 전: 자리 표시 `카드뉴스 01 / 07`, `디자인 재제작 예정`
- 이미지 배열만 교체하면 완성되는 구조
- 동작
  - 자동 전환 5초, 화면에 보일 때만
  - 마우스 올림·포커스·터치 누름 시 정지
  - 이전·다음 버튼, 점 표시기, 스와이프, 좌우 방향키
  - 움직임 줄이기 설정 시 자동 전환 끔
- Done when: 3가지 입력 방식 모두 동작, 슬라이드 전환이 스크린리더에 안내됨

### LF6 과정소개서 다운로드 (Must)
- 기존 과정리스트 다운로드 라이트 게이트 재사용 (담당자명, 회사·기관, 이메일, 필수 동의, 선택 이메일 수신)
- 자료 구분: '법정 과정소개서'
- 파일 미수령 상태: 파일 경로가 없으면 제출 성공 화면에서 `자료 준비 중입니다. 담당자가 이메일로 보내드립니다.` 안내 (시연용)
- 진입점: 히어로 2차 CTA, 자료 섹션 버튼
- 표시: PC·태블릿 가운데 모달, 모바일 바텀시트
- Done when: 입력 검증, 성공 상태, 모바일 바텀시트 동작

### LF7 법정 기준 (Must)
- 기존 AX5 데이터 재사용: 공통 법정의무교육 5종(근거·대상·주기), 차별점 비교, 연도별 시리즈
- 연도별 시리즈는 시리즈명과 연도만 노출 (외부 작품명 제외)
- 하단 안내문 기존 유지: 법적 근거·주기는 대표 표기
- Done when: 외부 작품명 0건, 모바일에서 표가 카드형으로 전환

### LF8 법정 문의 폼 (Must)
- 기존 문의 폼(HomeInquiry) 재사용, 좌측 안내 패널 카피
  - 제목: `매년 받는 법정교육,` / `KG에듀원에서 한 번에 관리하세요`
  - 본문: `우리 기업에 필요한 법정교육을 한 번에 안내합니다. 문의를 남겨주시면 담당자가 영업일 기준 1일 내 회신드립니다.`
- 관심 영역 '법정 필수' 자동 선택
- 희망과정 필드 (신규)
  - 7개 과정 체크박스 + 기타(직접 입력)
  - 1개 이상 필수, 기타 체크 시 입력 필수, 50자 이내
- 제출 데이터: 기존 구조 유지, 문의 내용 앞에 `[희망과정: …]` 토큰으로 기록
- 유입 경로: lead_source `legal`
- 나머지 필드·동의·첨부: 기존과 동일
- Done when: 5개 검증 케이스 통과, 홈·/kium 폼 동작 불변

### LF9 /content 연결 (Should)
- /content #ax5 하단에 `법정필수교육 과정·미리보기 전체 보기` 링크 → /legal
- #ax5의 외부 작품명 표기는 변경하지 않음 (운영 반영 여부 별도 결정, 프로토타입 범위 밖)

### LF10 반응형 품질 게이트 (Must, 전 기능 공통)
- 원 소스: 기기별 페이지·컴포넌트 분기 금지
- 기준 9폭: 1920 / 1440 / 1280 / 1180 / 1024 / 820 / 768 / 390 / 360
- 브레이크포인트: Design.md 목록만
- 통과 조건: 가로 스크롤 0, 겹침 0, 잘림 0, 터치 44px 이상, 입력칸 16px 이상, 로딩 흔들림 없음
- Done when: 9폭 캡처와 자동 검사 전부 통과

### LF11 측정 태깅 (Should)
- 기존 `data-ga-id` 규칙으로 태깅: 법정 칩, 히어로 CTA 2개, 미리보기 7개, 소개서 제출, 문의 제출
- GTM 코드 삽입은 하지 않음

## 6. UI/UX 설계 원칙

### 디자인 방향
> "공문서처럼 딱딱하지 않게, 광고처럼 요란하지 않게. 신뢰는 근거로, 친근함은 콘텐츠로."

- **기존 시스템 안에서 해결:** 토큰, 버튼, 카드, 섀도, 라운드, 브레이크포인트 신규 발명 금지
- **히어로는 /content와 같은 패턴:** 다크 스크림 + P4 방사형 톤. 구성안의 어두운 배경 의도는 살리되 사이트 문법 유지
- **색:** P4(웜)는 포인트에만. 강조 텍스트, 태그, 활성 상태
- **위계:** 페이지 1차 CTA는 '도입 문의하기' 하나. 소개서는 2차
- **카피 톤:** 존댓말, 느낌표 반복 금지, 과장 수식어 금지, 반말 금지
- **썸네일이 주인공:** 라인업 카드는 장식 최소화, 썸네일과 과정명이 먼저 읽히게

### 인터랙션
- 스크롤 등장: 기존 `.r` 규칙
- hover 효과: 마우스 기기에서만
- 슬라이더·모달: 기존 모션 토큰, 1초 이내, 바운스 금지

### 반응형 요약

| 모듈 | PC | 태블릿 | 모바일 |
|---|---|---|---|
| 히어로 | 좌 카피 / 우 모자이크 | 880 이하 세로 쌓기 | 모자이크 2×4 축소, CTA 전체 폭 |
| 라인업 | 4열 | 3열 → 2열 | 2열 → 560 이하 1열 가로형 |
| 자료 | 좌 슬라이더 / 우 자료 패널 | 880 이하 세로 쌓기 | 슬라이더 전체 폭 |
| 법정 기준 | 카드 5열, 표 | 카드 2열, 표 | 카드 1열, 비교 블록 |
| 문의 | 좌 패널 / 우 폼 2열 | 880 이하 패널 위 | 폼 1열, 희망과정 1열 |
